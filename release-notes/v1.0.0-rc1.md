# Data Analyst Today — v1.0.0-rc1

Prima release candidate pubblica del libro **Data Analyst Today — Analisi dati nell'era dell'AI**.

## Formati inclusi

La release allega direttamente:

- `data-analyst-today.pdf` — edizione PDF con outline/bookmark di navigazione;
- `data-analyst-today.docx` — edizione Word modificabile;
- `data-analyst-today.epub` — edizione EPUB con indice di navigazione.

## Stato editoriale

Questa candidate arriva dopo:

- review editoriale completa dei Capitoli 0–19;
- source/factual audit globale e freshness recheck;
- normalizzazione delle formule residue;
- proofread e consistency pass;
- front matter e reference layer;
- layout QA PDF/DOCX;
- release gate CI strict.

La build contiene 20 capitoli, 321 file Markdown nel corpo e 190 URL esterni distinti verificati nel source audit.

## Garanzie della pipeline

Prima della pubblicazione la pipeline verifica automaticamente:

- normalizzazione delle sorgenti;
- lint editoriale in modalità strict;
- build Markdown, DOCX, PDF ed EPUB;
- assenza di footnote Markdown irrisolte;
- outline PDF presente;
- repeating header sulle tabelle DOCX;
- frontespizio DOCX senza footer visibile;
- struttura EPUB valida (`mimetype`, container e documenti XHTML).

## Nota sulla candidate

`v1.0.0-rc1` è una **prerelease**. Il contenuto è congelato salvo bug dimostrati o problemi di pubblicazione. Licenza e metadata definitivi della prima release stabile restano decisioni separate.
