# Data Analyst Today — v1.0.0-rc2

Seconda release candidate pubblica di **Data Analyst Today — Analisi dati nell'era dell'AI**, scritto da **Alessandro Rapiti**.

Il repository continua a essere pubblicato attraverso l'account GitHub **KeyserDSoze**, ma l'identità editoriale dell'autore è ora distinta esplicitamente dall'account tecnico.

## Cosa cambia rispetto a RC1

Questa candidate migliora soprattutto la presentazione dei formati distributivi:

- autore corretto in frontespizio e metadata: **Alessandro Rapiti**;
- ogni nuovo capitolo inizia su una nuova pagina/sezione;
- titoli dei capitoli più grandi e con gerarchia visiva più netta;
- maggiore spazio bianco all'apertura dei capitoli;
- frontespizio DOCX e PDF centrato e più editoriale;
- stile EPUB aggiornato con titoli più evidenti, separazione visiva, tabelle e code block più leggibili;
- metadata autore verificati automaticamente in PDF, DOCX ed EPUB.

Il contenuto sostantivo del manoscritto non viene modificato da questo intervento: RC2 è principalmente una revisione di **identità editoriale e impaginazione**.

## Formati inclusi

La release allega direttamente:

- `data-analyst-today.pdf` — edizione PDF con outline/bookmark di navigazione;
- `data-analyst-today.docx` — edizione Word modificabile;
- `data-analyst-today.epub` — edizione EPUB con indice di navigazione.

## Stato editoriale

La candidate arriva dopo:

- review editoriale completa dei Capitoli 0–19;
- source/factual audit globale e freshness recheck;
- normalizzazione delle formule residue;
- proofread e consistency pass;
- front matter e reference layer;
- layout QA PDF/DOCX;
- release gate CI strict.

## Garanzie della pipeline

Prima della pubblicazione la pipeline verifica automaticamente:

- normalizzazione delle sorgenti;
- lint editoriale in modalità strict;
- build Markdown, DOCX, PDF ed EPUB;
- assenza di footnote Markdown irrisolte;
- outline PDF presente;
- repeating header sulle tabelle DOCX;
- frontespizio DOCX senza footer visibile;
- autore `Alessandro Rapiti` nei metadata PDF/DOCX/EPUB;
- gerarchia del titolo capitolo nel DOCX;
- struttura EPUB valida e stylesheet editoriale presente.

## Nota sulla candidate

`v1.0.0-rc2` è una **prerelease**. Il contenuto resta congelato salvo bug dimostrati o problemi di pubblicazione. Licenza e metadata definitivi della prima release stabile restano decisioni separate.
